# YOBUKO 呼子 — Studio + Multijoueur + DJ

YOBUKO tire son nom d'un autre nom du **Yamabiko**, le yōkai japonais de l'écho : tu lances
un son, un autre musicien te répond. [Pourquoi ce nom](README.md#pourquoi-yobuko-).

La présentation principale est désormais **en français**, centrée sur l'ambition du projet :
réunir la production musicale, la création à plusieurs et la préparation DJ dans une seule
application, de l'idée au live.

**[Lire la présentation complète](README.md)** · [English / technical overview](README.en.md)

Le studio repose sur [Suhina](https://github.com/suhina-daw/suhina-daw), l'analyse DJ intégrée
vient de [rbxport](https://github.com/chrisle/rbxport), et ce fork construit les liens avec
le multijoueur et une distribution commune. Le README distingue la vision des fonctions
actuellement disponibles et contient les crédits, l'avancement et les instructions d'essai.
